# Island

An Android app that puts a Dynamic Island-style pill over your phone's camera and shows **notifications from every app** in it. Built for the Poco X8 Pro Max on HyperOS, but it should work on any Android 11+ phone with a punch-hole camera.

HyperOS already has its own island (Hyper Island), but it only shows apps that integrate with Xiaomi's API, like music, calls, and alarms. This app fills the gap for everything else.

## What it does

- Shows a small always-on pill over the camera.
- When a notification arrives, the pill expands with the app icon and title, then returns to idle.
- Tap the pill to expand it and read the full text. Tap again to open the app. Swipe up to dismiss.
- Tap the idle pill to replay the last notification.
- Steps aside while music, a call, an alarm, or navigation is active, so the system island can show them.
- Position and size are adjustable from inside the app.


## Set up on the phone

1. Install the APK. If Play Protect blocks it, tap **More details → Install anyway**.
2. Open **Island** and tap **Allow display over other apps**.
3. Tap **Allow notification access**. If it's greyed out, go to Settings → Apps → Island → ⋮ → **Allow restricted settings**, then try again.
4. Press **Test island**. A pill should appear over the camera.
5. Use the sliders to line the idle pill up with the camera hole.


## Privacy

The app reads notification text only to show it in the pill. It doesn't store it, log it, or send it anywhere.
